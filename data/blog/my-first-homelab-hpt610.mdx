There's something uniquely satisfying about breathing new life into old hardware. I was doom-scrolling on Carousell one day to find cheap or free items people wanted to let go. Then, I stumbled upon an old office computer for **just RM 60** (about USD ~13 converted), quite cheap! I was looking for few candidates previously but didn't fit my budget, so I think this time is a good oppurtunity to grab one. I bought one.

First impression, I liked the form factor that **wouldn't take up much space**, and the specs were quite OK for a beginner person (like me) who just **started on homelabbing**.

## Unboxing

The model I've gotten is an **HP T610**. Rocking an **AMD T56N** (dual core) processor, comes with **4 GB RAM** and **16 GB flash disk**. I've upgraded some of the components. I figure the RAM and storage were quite small and limited, which leads to some upgrades!

What's come in the box? Complete set including power adapter, stand base, and the computer itself. Lucky it comes with power adapter because HP is using proprietary jack for their power supply input.

## Limitations

After a few months using it, I can say it works flawlessly of low to medium load application. But, I discover one weaknesses that worth noting, and it's is regarding the CPU.

As mentioned above, the CPU AMD T56N is **more than a decade old CPU**. It's from the first generation of AMD's Embedded G-Series System-on-Chip (SOC) released back in 2011.

The microarchitecture is based on [Bobcat](<https://en.wikipedia.org/wiki/Bobcat_(microarchitecture)>). Most CPUs, even the old ones, support `AVX`, `AVX2`, `AVX512`, `SSE4`, and `SSE4.2`. The T56N supports **none** of these, it doesn't have any [`AVX`](https://en.wikipedia.org/wiki/Advanced_Vector_Extensions) instructions set and the [`SSE`](https://en.wikipedia.org/wiki/Streaming_SIMD_Extensions) instruction set is only implemented up until `SSE3`. Some modern applications and media codecs **simply won't run, or will run very slowly** (using software fallback), on this machine.

I have encountered several real issues due to lacking of CPU instruction sets. The first being the the [bun](https://bun.com/), the Javascript runtime, [require SSE4.2 and AVX support](https://bun.com/docs/installation#cpu-requirements). Some application that we build around bun cannot run on my machine.

Second, I cannot run [MySQL Docker image](https://hub.docker.com/_/mysql) version 8 and had to fallback older version of MySQL.

Third, I had issue my Jellyfin was crashing randomly during usage version upgrades. Some people were [reporting](https://github.com/jellyfin/jellyfin/issues/15148#issuecomment-3446563763) the same thing and turns out it's the sqlite library they use start requiring `SSE4.1`, which this machine doesn't have. The workaround is to replace the sqlite binary from older jellyfin versions.

Some issue do have some workarounds to solve this, but more and more apps and platforms are **phasing out CPU this old** (very sad). For example, **.NET 11** have updated their baseline requirement [to require AVX and modern SSE instruction sets](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-11/runtime#x86x64-requirements). I guess this is the limitation I'll have to live until I got a newer server in the future.

I try to not let is continuously run 24/7 because non of the components are rated for actual server use. For example, the HDD I've added is from a laptop, which is not designed for constant operation like server-grade drives. Hence, those components may fail early if subjected to continuous heavy usage.

One my my friend had an issue where the hard disk fail on him after few years using it. He was using non server grade HDD either. This made me cautious about the longevity of my own setup.

But if I wanted to use it, I don't hold myself back from doing so, nothing live forever so might as well enjoy it while it lasts.

## Conclusion

I put the server at the living room because that's where my router is. The server connected to the router via ethernet. Here it is, sitting quitely and serve it purposes when I need it.
